# ADR 004: Использование Redis/Valkey для идемпотентности и блокировок

## Проблема

Битрикс24 может отправлять дубликаты событий, а несколько воркеров могут одновременно обновлять
одну сделку.

## Решение

Использовать ключи Valkey через `SET NX` с TTL для быстрой идемпотентности и распределённых
блокировок с токеном владельца. Дополнительные гарантии дают ограничения уникальности PostgreSQL
и долговечные записи событий.

## Альтернативы

Только блокировки базы данных; карты в памяти процесса; приём дубликатов с последующей компенсацией.

## Обоснование

Valkey предоставляет быстрые атомарные операции между экземплярами, а PostgreSQL остаётся
авторитетным источником данных.

## Последствия

Приём вебхука зависит от доступности Valkey, TTL блокировки должен превышать обычное время
обработки, а каждый ключ обязан иметь ограниченный срок жизни.
