# ADR 003: Использование PostgreSQL

## Проблема

Состоянию автопарка, связям, ограничениям уникальности, транзакциям, outbox событий и диагностике
нужен надёжный источник истины.

## Решение

Использовать PostgreSQL через Prisma, хранить миграции в репозитории и применять
детерминированный seed.

## Альтернативы

MySQL для всех систем; документная база данных; Битрикс24 CRM как единственное хранилище.

## Обоснование

PostgreSQL предоставляет надёжные транзакции, JSONB для полезной нагрузки, индексы и чёткую
границу с MySQL-базой коробочной версии Битрикс24.

## Последствия

Миграции схемы и резервное копирование обязательны; JSON-поля не должны превращать доменную
модель в набор нетипизированных данных.
