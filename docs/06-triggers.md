# 06. Триггеры и внешние статусы

| Fleet        | Стадия Bitrix24             |
| ------------ | --------------------------- |
| `ASSIGNED`   | Транспорт назначен          |
| `LOADING`    | На погрузке                 |
| `IN_TRANSIT` | В пути                      |
| `DELIVERED`  | Доставлено                  |
| `CLOSED`     | Успешно закрыто             |
| `CANCELLED`  | выбранная неуспешная стадия |

Worker вызывает `crm.item.update` с настроенным `stageId`. Нативные триггеры Bitrix24 подходят для
простых сценариев, но worker отвечает за повторные попытки, диагностику и `correlationId`.

Чтобы не возникал цикл событий, перед обновлением сравниваются текущие и желаемые значения.
Проверяйте каждое сопоставление отдельно; неизвестный статус не должен менять сделку.
