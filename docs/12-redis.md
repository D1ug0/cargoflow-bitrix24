# 12. Redis / Valkey

Valkey хранит только временную координацию:

- `cargoflow:webhook:<sha256>` — идемпотентность webhook через `SET NX EX`, TTL по умолчанию 24 ч;
- `cargoflow:lock:deal:<id>` — блокировка синхронизации сделки на 30 секунд;
- Lua-скрипт снимает блокировку только при совпадении токена владельца.

Если хранилище идемпотентности недоступно, webhook отвечает `503`: принять событие без защиты от
дублей небезопасно. Надёжная история остаётся в PostgreSQL. Любой новый cache должен иметь
источник истины и ограниченный TTL.
