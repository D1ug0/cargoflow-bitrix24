# 13. Fleet Domain

`Vehicle` содержит госномер, тип, грузоподъёмность, статус, город и водителя. `Driver` содержит
имя, телефон, категории прав и статус. `Trip` связывает сделку Bitrix24 с машиной/водителем и
хранит маршрут, даты и статус.

```text
CREATED -> ASSIGNED -> LOADING -> IN_TRANSIT -> DELIVERED -> CLOSED
    \          \          \            \
     +----------+----------+-------------+-> CANCELLED
```

Перескок стадий даёт `409`, недоступная машина — `409`, неверные даты — `422`. Закрытие или отмена
освобождает машину и водителя в одной транзакции. `bitrixDealId` и госномер уникальны. Seed создаёт
две свободные машины с водителями и одну машину в сервисе.
