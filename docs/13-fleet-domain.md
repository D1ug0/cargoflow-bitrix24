# 13. Fleet Domain

`Vehicle` содержит госномер, тип, грузоподъёмность, статус, город и водителя. `Driver` содержит
имя, телефон, категории прав и статус. `Trip` связывает сделку Bitrix24 с машиной/водителем и
хранит маршрут, даты и статус.

```text
CREATED -> ASSIGNED -> LOADING -> IN_TRANSIT -> DELIVERED -> CLOSED
    \          \          \            \
     +----------+----------+-------------+-> CANCELLED
```

Перескок стадий даёт `409`, недоступная машина — `409`, неверные даты — `422`. Закрытие или отмена
освобождает машину и водителя в одной транзакции. `bitrixDealId` и госномер уникальны. Seed создаёт
две свободные машины с водителями и одну машину в сервисе.

На странице «Транспорт» можно совместить поиск по госномеру/водителю с фильтрами по статусу,
типу кузова и городу. Город ищется по части названия без учёта регистра. Фильтры применяются
автоматически через существующий `GET /vehicles` и сохраняются при переходах между страницами
dashboard. Кнопка «Сбросить» очищает все четыре фильтра и возвращает полный список транспорта.

Рейс можно создать без экипажа в статусе `CREATED`, а затем вызвать
`PATCH /trips/:id/assignment`. Операция разрешена только до начала перевозки, атомарно переводит
машину и водителя в `IN_TRIP` и сам рейс в `ASSIGNED`. Если машину успел занять другой запрос,
возвращается `409`. Перейти из `CREATED` в `ASSIGNED` одним изменением статуса без машины нельзя.
