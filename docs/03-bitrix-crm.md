# 03. Настройка CRM Bitrix24

## Порядок настройки учебного портала

1. В настройках CRM создать направление сделок **Грузоперевозки**.
2. Перенести стадии из `bitrix/config/pipeline.json`, сохранив порядок и тип результата.
3. Создать поля из `bitrix/config/deal-fields.json` и разделы карточки: Клиент, Маршрут, Груз,
   Перевозка, Автомобиль, Финансы, Интеграция.
4. Для компании, контакта, телефона и email использовать стандартные поля Bitrix24.
5. Сделать города маршрута, даты и груз обязательными перед выходом со стадий расчёта/поиска.
6. Записать реальные ID направления, стадий и полей в `.env`. Новая REST-интеграция использует
   `crm.item.*` и имена полей в `camelCase`.
7. Создать пример из `bitrix/config/test-deal.json`: провести его по успешному пути и сделать копию
   для проверки неуспешной стадии.

ID из примеров нельзя считать переносимыми. После настройки приватного входящего webhook получите
данные своего портала через `GET /api/bitrix/stages` и `GET /api/bitrix/deal-fields`.

Для отчёта сохраните воронку, заполненную карточку, проверку обязательных полей и сделки с двумя
исходами. Предварительно скройте контакты и полный адрес webhook.
