# Артефакты настройки Bitrix24

Эти файлы — независимая от конкретного портала спецификация. Это не скрипт, который можно
безопасно запустить в неизвестном аккаунте Bitrix24. Создайте в учебном портале направление и
поля, затем перенесите созданные порталом ID категории, стадий и полей в `.env`.

Порядок настройки:

1. `pipeline.json` — создать направление **Грузоперевозки** и его стадии.
2. `deal-fields.json` — создать поля сделки и разложить их по разделам карточки.
3. Выполнить инструкции `docs/04-permissions.md` — `docs/07-business-processes.md`.
4. Создать пример из `test-deal.json` и провести сделку через воронку.
5. Получить реальные стадии и поля через `GET /api/bitrix/stages` и
   `GET /api/bitrix/deal-fields`, затем обновить `.env`.

Не записывайте сюда настоящий адрес входящего webhook или исходящий `application_token`.
